# DevQuest — Learn C# & .NET by Playing

A Duolingo-style, addictive learning game for C#/.NET, built with Blazor WebAssembly + ASP.NET Core + SQLite, fully bilingual (English/Spanish). Empty greenfield directory; .NET 10 SDK is installed, so we target `net10.0`.

**Game identity:** a robot mascot — **Bit** — guides the player through a world map of technology islands. Every lesson = small win, XP, combos, streaks, boss battles. Bit is also the live AI tutor **with a voice**, and stars on the completion certificates.

## Architecture

```
D:\Projects\learnai\
  DotNetQuest.sln
  src/
    DotNetQuest.App/          # Blazor Web App host (server): auth, minimal APIs, EF Core + SQLite
      Endpoints/              # /api/me, /api/progress, /api/code/run, /api/tutor/chat,
                              # /api/leaderboard, /api/certificates, /signin-google...
      Services/               # AiTutorService (OpenAI-compatible), CodeRunnerService, CertificateService (QuestPDF)
      Data/                   # EF Core DbContext, entities, migrations, learnai.db
    DotNetQuest.App.Client/   # WASM client: game UI, engine, i18n, content packs
      wwwroot/content/worlds/*.json    # bilingual lesson content (data-driven)
      wwwroot/i18n/en.json, es.json    # UI strings
    DotNetQuest.Runner/       # sandboxed console worker: compiles & runs user C# (Roslyn)
  tests/DotNetQuest.Tests/    # xUnit engine tests + bUnit component tests
```

- **Blazor Web App** template with `InteractiveWebAssembly` render mode (client game logic runs in WASM; server serves APIs + static assets).
- **Google login:** ASP.NET Core cookie authentication + `AddAuthentication().AddGoogle()` on the server. You'll create a Google Cloud OAuth Client ID/Secret (documented step-by-step in the README, redirect URI `https://localhost:xxxx/signin-google`); credentials go in `appsettings.json`:
  ```json
  "Authentication": { "Google": { "ClientId": "<YOU-FILL>", "ClientSecret": "<YOU-FILL>" } }
  ```
  WASM client calls cookie-protected APIs; `/api/me` returns the session profile.
- **SQLite via EF Core** on the server. Tables: `Players` (Google subject id, email, **nickname**, **avatar**, XP, level, streak, gems, settings JSON, certificate name), `LessonProgress` (status, stars, attempts), `ExerciseAttempts` (spaced repetition), `Achievements`, `DailyActivity` (streaks/quests), `Submissions`, `Certificates`.
- **Real C# execution from day one:** `POST /api/code/run` spawns `DotNetQuest.Runner` (separate process → infinite loops killed by timeout). Runner reads JSON {code, test cases} from stdin, compiles with Roslyn, captures stdout, checks expected output/assertions, returns JSON. Allowlisted assembly references only (System.Runtime, Console, Linq, Collections, Text, Regex; IO only for the CLI world), unsafe disabled, 10s timeout, 64KB output cap.
- **i18n:** lightweight JSON dictionary service (`T("key")`), EN/ES UI strings; lesson content stores `{"en": "...", "es": "..."}` inline. Language switch persisted per player, defaults from browser.
- **UI:** MudBlazor for primitives + custom game theme (islands map, mascot, confetti, sounds via JS interop). Dark mode included.
- **Bit artwork:** Bit is an original SVG mascot (poses/emotions: happy, thinking, celebrating, sleeping, face-palm) reused across the game UI, chat, avatars, and certificates.

## Login & Onboarding

- **Sign in with Google** button on the landing screen (Bit waving). First login → **onboarding flow**: pick your **nickname** (validated, unique) and choose an **avatar** from a fun set of Bit-style robots (colors + accessories). Nickname/avatar editable later in profile.
- Profile stores an optional **"certificate name"** (full name) used only on PDF certificates; nickname is used everywhere else.
- Progress is tied to the account, so it follows the player across browsers/devices.

## Leaderboard

- **Top 10 players by points** — rank, avatar, nickname, XP, streak, level; the player's own row is highlighted even if outside the top 10.
- Two tabs: **All-time** and **This week** (weekly XP resets every Monday — Duolingo-style league feel).
- `GET /api/leaderboard?range=all|week` — simple indexed SQLite query over `Players` / `DailyActivity`.

## AI Tutor — "Bit" (built into the core)

A fun, energetic robot coach available on every exercise and in a free-chat drawer — **and it talks**.

- **Backend:** `POST /api/tutor/chat` proxies to **any OpenAI-compatible provider** (DeepSeek, OpenAI, Azure OpenAI, OpenRouter, Ollama, LM Studio…). `AiTutorService` is a thin `HttpClient` client: configurable `BaseUrl` + `ApiKey` + `Model`, standard `/chat/completions` JSON. **The API key lives only server-side** in `appsettings.json` (you'll fill it in) and never reaches the browser.
- **appsettings.json (default = DeepSeek per your request):**
  ```json
  "AiTutor": {
    "BaseUrl": "https://api.deepseek.com",
    "ApiKey": "<YOU-FILL-THIS-IN>",
    "Model": "deepseek-flash",
    "Temperature": 0.7,
    "MaxTokens": 800
  }
  ```
  Model name is just config — switching providers is a 3-line change, no code.
- **Persona (system prompt):** Bit is upbeat, playful, uses short punchy sentences, celebratory emojis, game lingo ("XP", "boss battle"), and always replies in the player's selected language (EN/ES). Bit teaches Socratically: hints, guiding questions, small nudges — **never the full solution on the first ask** (escalates over successive asks).
- **Context injection:** every ask includes lesson title, exercise instructions, the player's current code, and the last runner output/errors — so hints are about *your* broken code.
- **Client UI:** "Ask Bit" button on every exercise + floating chat drawer with the mascot, typing animation, message bubbles. Conversation resets per exercise.
- **🔊 Bit's voice:** Bit *speaks* its replies using the browser's built-in speech synthesis (Web Speech API via JS interop — free, offline-capable, no API costs). Best available EN/ES voice is auto-selected per language, with pitch/rate tuned to sound energetic; Bit's mouth animates while talking. Speaker button on every Bit message + optional auto-speak toggle in settings; voice buttons hide gracefully if the browser doesn't support it. Config-gated option for future neural TTS through the provider.
- **Resilience:** every exercise ships 2-3 static bilingual hints as fallback; if the AI endpoint is unreachable or the key is missing, Bit serves those instead and the game stays fully playable offline.
- **Gamified guardrail:** first 3 Bit hints per lesson are free, then they cost gems (balance tuned in Phase 2).

## Certificates (PDF, with Bit)

- **`GET /api/certificates/{worldId}`** (server-side **QuestPDF**) returns a downloadable, print-ready PDF certificate when a world is completed 100%.
- **Fun design:** colorful game-style certificate — Bit's mascot artwork (celebrating pose), world badge, big "Certificate of Completion" title, **the developer's name** (certificate name, falling back to nickname), **completion date**, plus fun stats (XP earned, stars, streak). Fully bilingual per player language.
- **Per world + grand finale:** one certificate per completed world/track, plus a special "Graduation" certificate for finishing the entire curriculum.
- **Validation:** server re-checks LessonProgress before issuing; issued certificates recorded in SQLite so they can be re-downloaded from the player's trophy shelf. Bit SVG rasterized with Svg.Skia for embedding.

## Delivery Phases

**Phase 1 — Foundation + game core + World 1 + AI tutor core (the big one)**
Solution scaffold (3 projects + tests), SQLite/EF Core with migrations, **Google OAuth + cookie auth + onboarding (nickname + avatar picker)**, i18n service EN/ES for all UI, exercise engine (MCQ / fill-blank / output prediction / type-in / free-code), Roslyn runner worker + API, **AI tutor: AiTutorService + /api/tutor/chat + Bit chat UI with typewriter animation + speech synthesis voice + static hint fallback**, XP + streaks persisted, **basic all-time top-10 leaderboard**, world map + lesson player UI with game theme, Bit SVG mascot with poses, World 1 "C# Fundamentals" (~25 lessons, fully bilingual), Playground page. Exit criteria: a new player signs in with Google, sets nickname + avatar, plays World 1 end-to-end (writing real code that runs), asks Bit for hints about their code **and hears Bit speak**, sees XP/streak saved in SQLite, appears on the leaderboard, and switches EN↔ES everywhere.

**Phase 2 — Gamification + CLI world + tutor polish**
Hearts, daily goal/quests, achievements (30+), gems shop (incl. Bit hint costs), combos, SFX/confetti/animations, Boss Battles, Lightning mode, Practice mode, **Bit's Daily Challenge + double-XP weekends + daily login bonuses**, Parsons + bug-hunt + match-pairs exercise types, **tutor streaming via SSE + proactive nudges after failed attempts**, **weekly leaderboard tab**, World 4 "CLI & Console" deep content + World 2 "Methods & Collections", first cheat sheets.

**Phase 3 — Data + Web worlds + certificates**
World 7 EF Core (real EF exercises run via the runner with per-submission SQLite), World 8 ASP.NET Core Web APIs, World 3 OOP, **PDF certificates via QuestPDF (per-world + graduation, Bit artwork, name + date + stats, trophy shelf)**.

**Phase 4 — Modern C# + Desktop + Multi-platform worlds**
Worlds 5 & 6 (LINQ, async/records), World 10 WPF/WinForms, World 11 MAUI, World 9 Blazor, glossary + Bit personality polish.

**Phase 5 — Pro skills + polish & ship**
World 12 Testing/DI/Patterns/Performance, PWA offline support, export/import progress, dark-mode + accessibility pass, bilingual content proofread, balance tuning, final visual QA with screenshots.

Each phase ends with: solution builds green, unit tests pass, app runs locally (`dotnet run`), and gameplay verified in the browser. Git repo initialized at Phase 1 start, one commit per phase.
